# Paper

`PaperJK7.tex` and `PaperJK7.pdf` are the current manuscript. PaperJK3--6 are
stored under `archive/paper_versions/`.

Figures used by PaperJK7 are generated by the current modules documented in
`pipeline/README.md`. Every image referenced by the TeX source is copied into
this directory, so the manuscript compiles without paths outside `paper/`.
Run `make sync-paper-assets` after regenerating figures, then `make paper`.
