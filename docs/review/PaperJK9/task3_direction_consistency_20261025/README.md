# Task 3：一阶与非线性模型的方向一致性

当前目标：固定同一套原参数和初始分布，比较设计变量变化引起的质量变化方向；不要求质量水平、变化幅度或精确质量保持一致。不重估参数，不重新优化奖金/期限/精度，不认证全样本最优性或节省幅度。论文和正式实现未修改。

## 本轮检查

## 有明确独立支持的方向反例

2551固定原期限和原反馈，只提高奖金10%：一阶质量变化约+.124268；隐式梯度HJB结果约−.018998。独立价值HJB/产出方法给出约−.019240；降低奖金10%则一阶约−.124268、独立非线性约+.019454。因此该代表点确有奖金方向不一致，不能归因于同时改变期限或要求精确质量保持。是否对应比赛的后验平均方向也相反，尚未检验。

反馈精度的微小变化不能只按点估计符号判断；未超过数值诊断半径的项已列为不确定。2464的反向结果量级很小；后续独立方法与两层反馈配对检查支持同一符号。2551精度反向也已由独立价值HJB复核。原因与适用范围见[查因报告](cause_findings.md)。
