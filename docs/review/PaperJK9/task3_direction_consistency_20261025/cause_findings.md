# 方向不一致：查因结论

本轮只查方向不一致的成因，固定原参数，不重估后验、不重新优化，也不恢复已删除的精确质量保持支线。结果限定于原代表联合点及本轮数值精度，尚未证明对应比赛的后验平均方向。

## 结论

没有发现原参数提取、原链字节、奖金/时间单位、初始方差或MCMC收敛错误。已确认的直接原因是近似截断：2551原激励尺度下的非线性战略反应，以及部分反馈比较中极弱的一阶效应被高阶项覆盖。不能由此断言估计参数是真值，或排除先验/结构设定对参数位置的影响；采样收敛不是结构估计准确性的证明。

## 输入、公式和单位

六例逐一将保存代表点与原接受链的联合行比较，最大参数差不超过9e-16；全部原链SHA一致。原数据奖金经原PRIZE_DIVISOR换算、期限由N_Delta*Delta2f计算，均与比较输入一致。S0始终取原sigma/sqrt(lambda_obs)，不随精度干预重设。所有原接受链无divergence，rank Rhat及既有诊断通过。

一阶实现与JK9附录的B^(1)=beta+theta*A一致；非线性价值HJB的双方自项、交叉项和产出漂移恒等式也对应同一个游戏。未发现一个模型使用另一套初值、参数或方向定义的错误。证据为[cause_input_audit.json](cause_input_audit.json)及代码中的源哈希。

## 2551奖金：原尺度下双方反应不同，一阶固定努力比捕捉不到

代表点激励指标约w_i=4.216、w_j=2.259；原后验w_i中位约3.842，95%约[1.759,7.559]。这不是一个已经得到小激励误差保证的区域；数值1不是新设的准确性阈值。

固定成本、sigma、mu、S0、期限和精度，将整个奖金尺度下调后再比较其上下10%：

|奖金中心尺度（原值=1）|一阶质量变化：上端减下端|非线性变化|方向|
|---|---:|---:|---|
|.01|+.00248536|+.00249771|一致|
|.10|+.02485360|+.02576021|一致|
|.30|+.07456080|+.07398828|一致|
|1.00|+.24853600|−.03869384|相反|

没有重估任何参数，方向便随激励尺度由一致转为相反，支持高阶战略效应的解释，而不是两个模型使用了不同估计参数。

在奖金从原值.9升至1.1的模型内核算中：较低成本选手i的累计预期努力从1.03615变为1.03447，较高成本选手j从.13727降至.07468，总努力下降。质量变化约−.038694，其中半数累计总努力变化约−.032136、配置项变化约−.006558。

一阶策略m_i=theta*G_Q/c_i、m_j=theta*G_Q/c_j，将双方努力比固定为c_j/c_i，不能描述该差异化战略反应。保留一阶策略、只改用完整状态传播，质量变化仍为正（约+.207148）；换成非线性策略后才转负。因此这组奖金比较中的方向翻转主要由策略修正引起，不能全部归因于状态传播。

这说的是模型内累计预期努力，不能表述为真实选手在数据中放弃，也不能声称每个状态下努力都下降。该分解以.9和1.1为两端，不是从原值提高10%的单边差。

## 反馈：一阶项太弱，高阶项可改变符号，即使整体质量很接近

固定原参数与期限，一阶反馈方向来自(1/c_i-1/c_j)*H(lambda)。初始均值mu=0或成本相等时，该精度项消失；其很小时，控制质量水平误差并不保证反馈变化的符号。对固定有限精度的一阶展开，Delta B = theta*Delta A + O(theta^2)，符号还需要theta*Delta A超过余项，不能仅由O(theta^2)推出。

2551：独立价值HJB确认原奖金下精度减半使质量约+.022316、加倍使质量约−.019024，均与一阶相反。将奖金降至原.1倍后，减半约−.000107、加倍约+.0000926，方向恢复一致；降至.01和.001倍时也一致。这排除了精度反向只来自原隐式核的解释。

2464：其w虽小，原尺度下一阶预测精度减半的质量变化仅+5.3843e-7，独立非线性方法却为−3.9947e-6；精度加倍一阶−3.8263e-7，非线性+3.4628e-6。两个独立价值网格的配对变化差仅约2.1e-9，且与原隐式核方向相同，支持微小反向并非简单网格噪声。

把2464奖金降至原.01倍后，同样的精度减半比较变为：一阶+5.3843e-9、非线性+4.8966e-9；精度加倍一阶−3.8263e-9、非线性−3.4126e-9，方向均恢复一致。这里原质量水平约3.2885，几百万分之一的变化就能导致符号相反；不能将其夸大为质量水平近似严重失效，也不能忽略方向反例。

## 估计在其中扮演什么角色

原参数是近似模型下、给定原先验和经验初始化的推断。它决定实证比较落在哪个激励范围；成本与提交尺度r的有限样本分离较弱，因而先验可能影响位置。这是额外的估计不确定性，但本轮没有发现估计程序算错，也没有识别结构偏误的大小。

固定同一参数便可复现方向差异；奖金缩小后方向恢复，说明近似阶数本身足以造成当前反例。不能为使方向一致而随意改成本、sigma或奖金单位。下一步若扩展范围，应使用原联合后验核查平均方向；本轮不擅自恢复非线性重估。
