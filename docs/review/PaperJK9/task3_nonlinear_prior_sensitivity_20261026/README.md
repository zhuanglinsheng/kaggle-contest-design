# Task 3：原模型下的成本先验与边界方向敏感性

日期：2026-10-26。用户授权补完有针对性的敏感性检查，以方向一致为主要标准，同时记录幅度变化。正式论文和现有表格暂不修改。

## 最终结果

**本轮有针对性的检查已完成。四场比赛、两项替代设定的八个比较，均找到沿原联合方案方向降低成本且质量得到正方向数值支持的设计；七项支持原具体方案，一项需要缩小降奖金幅度。** 这证明这些代表案例中的改善方向并非仅靠基准成本先验或0.01下界成立，不证明各设定下最优设计或精确节省比例恒定。

|比赛与情景|原方案的方向与节省|共同成本log SD放宽至1|成本下界降至0.001|
|---|---|---|---|
|8219，δ=2|完全披露、期限不变、微幅降奖金；节省0.001204%|原方案通过|原方案通过|
|2464，δ=100|期限缩短50%、奖金变为原来的14.823倍；节省60.57%|原方案通过|原方案通过|
|5144，δ=1|降低反馈、期限不变、奖金降低7.05%；节省3.53%|原方案通过|原方案通过|
|2551，δ=0.1|期限延长50%、奖金降低56.05%；联合方案节省39.59%|原方案通过|原降奖幅度无法确认；改为降低34.28%奖金后通过，仍节省19.80%|

表中的“原方案通过”意味着新后验下仍支持这一具体方案，并非重新估计出的最优节省恰好不变。固定同一奖金、期限时，其成本按定义不随参数后验变化；本轮重新检验的是维持质量的条件是否成立。调整后的19.80%也是找到的可行方案节省，不是新最优值。

8219的首轮128粗层+16细层多层积分无法判定方向；仅对此微小效应补充同128个联合后验抽样的直接细网格积分，保留全部抽样。两种设定下原方案的质量差分别为0.00005533与0.00001876，扣除积分与网格诊断后的下界分别为0.00003950与0.00000833，均为正。旧结果保留，不以旧多层积分的正负点估计代替判定。即使方向通过，0.001204%的节省仍很小，不能强调其实际重要性。

### 必须区分联合方案与反馈成分

5144在相同奖金、期限下，弱反馈相对保留原反馈的质量差，基准及两项替代设定均为正，分别约0.03342、0.05891、0.03725。因此，该例反馈降低本身的效果也得到方向支持。

2551原联合方案还提高了绝对反馈精度。但将奖金、期限固定后，提高反馈精度相对保留原反馈的质量差，在基准及两项替代设定下均为负，约−0.00468、−0.00615、−0.01292（下界放宽时最后一项对应调整后的奖金）。**因此该例只能支持“延长期限、降低奖金的联合方案仍可改善”，不能作为“提高精度本身有益”的证据。** 基准本来也是负方向，不能说这是先验改变引起的新反转。其余完全披露案例的独立反馈成分在初始多层积分中未能可靠判号，不将联合方案通过等同于每个变量单独改善。

### 结论的范围

两项成本设定变化下，所选四例的联合改善方向得到支持；一例奖金调整幅度明显变化，说明“方向稳健”不等于“幅度稳健”。这是一组针对性检查，可以回应Jussi要求的代表设计及成本先验/边界敏感性证据；不外推到73场、所有合理先验或连续域全局最优。估计仍用原一阶似然，所有反事实质量都用原非线性模型。本轮未改论文、表格或PDF，三个正式文件的哈希均与开始前一致。

## 冻结范围

选择四场：8219、δ=2（原表极小节省）；2464、δ=100（大幅增加奖金）；5144、δ=1（相同期限下弱反馈、降低奖金）；2551、δ=0.1（延长期限、降低奖金和提高绝对反馈精度）。这是针对现有非线性表格的目的性抽样，不是全样本统计检验。

两项替代设定分别改变一个因素：共同 log 成本尺度标准差从 0.75/√2 放宽至 1，保留均值0、成本下界0.01及相对 log 成本高斯因子；成本下界从0.01降至0.001，保留原先验。双方下界会耦合共同与相对成本，因此不声称截断后的相对成本边际分布恒定。其他参数先验及似然不变。

仓库已有全部八组通过诊断的直接NUTS重估后验。先核查四链哈希、原始数据及其余先验输入、模型/可执行文件哈希，再复用；不以旧一阶反事实代替本轮计算，不用重要性权重近似新后验，也不重复估计相同后验。审查见[manifest.json](manifest.json)。

## 判断标准与计算

1. 固定论文所选方案的绝对反馈精度、期限与奖金，在新后验下，配对比较候选方案与原比赛方案的原非线性均衡质量。初始分布在同一参数抽样内跨设计保持不变；每种先验重新计算自身的原方案质量基准。
2. 若原方案通过正方向诊断且成本下降，直接确认这一方向仍存在可行改善，不要求节省幅度相同。
3. 若未通过，只对奖金做有限调整：从原候选奖金向保持原奖金调整方向且不超过原预算的上界移动50%、75%、87.5%、93.75%。期限和绝对精度固定；找到通过的方案即停止。该步骤检验沿原方向是否仍存在改善，不声称重新找到了最优期限或精度，也不把未通过的点视为不可行。
4. 在所用奖金和期限下，另与保留原反馈的方案配对比较，单独记录反馈成分的作用。联合方案改善不等于反馈成分单独改善。

沿用现有表的原模型求解器、跨坐标恢复及配对多层积分：每链32个粗层和4个独立细层抽样，共128+16；保留每个联合参数抽样的相关性，四链等权。均值差由粗层差加细层修正得到。方向以均值差±t临界值×积分MCSE再加网格诊断半径判断，分别记录正、负、无法判定和求解未确定；该区间不是参数后验可信区间，网格半径也不是严格连续PDE误差界。失败抽样不删除，不平均成功子集。

所有奖金试探在[run.py](run.py)中预先固定。计算以[status.json](status.json)和[run.log](run.log)为准；八项结果写入results/。最终判断需区分原具体方案是否有效、调整幅度后是否仍存在同方向改善，以及固定奖金期限下的反馈成分效果。即使全部通过，也只支持这些代表案例与两项替代设定，不能推广成全样本最优设计或所有先验下的稳健性。
