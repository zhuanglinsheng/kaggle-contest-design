## 更弱反馈：已尝试但不能接受的结果

此前工作测试了逆值坐标、指数拟合、对数变量、解析高斯基准分离、直接隐式值函数、最佳回应/策略迭代及复合网格等路线。它们是求解器试验，未进入论文输入。

已有明确的拒绝依据包括：

1. 不同分辨率的组织者产出仍明显变化。
2. 积分或 Newton 时间步不能推进至完整期限。
3. 密度、价值边界或梯度检查不合格。
4. 离散最佳回应收益虽然很小，但独立净漂移收益核算仍显示较大差异。

例如，同一弱反馈基准在一个有限状态跳跃近似中，初始状态最大偏离收益约为 `5.10e-06`，而与单独净漂移收益评价的最大差异约为 `0.135`；另一个复合网格试验的初始偏离收益约为 `0.0207`。这些结果不能用于确认原模型的类别。

上述例子均为 `sigma=0.06`、`alpha=2.164248520857008`、`T=0.7656981839261894`、`lambda=0.001`。不同例子使用不同离散方法，不能直接当作同一方法的收敛对比。收益差异也只是两个数值评价的差异，不是对真实连续解误差的严格估计。

试验记录及源代码快照：`results/theory/numerical_joint_plane_solver_experiments/20261024/observations.json` 及同目录文件。保留这些记录的目的是避免重复失败路线，而不是认证其中任何近似解。

## 与 Task 3 价值坐标方法的联系，尚未解决剩余有限精度候选

Task 3 的完全披露输出方程改用价值坐标后恢复了 3 个后验 BVP 节点上限失败；见[方法](task3_full_disclosure_value_grid_method_20261025.md)。这是完全披露的线性输出计算，不表示 Task 2 的强激励小正精度 Nash 系统已解决。

回查此前 `contest_inverse_logphysical.py`，已存在逆坐标及 log 导数试验，且产出加密不稳定。因此不能将“改用逆坐标”本身当作未经尝试的新解法。若继续，应区分新的直接局部离散、端点 logit 加密与原指数拟合/log 导数方法，并重新通过独立原状态收益/产出检查。

供接续复核的精确变换：以 `q0=S0+sigma²*T` 归一化，`e_k=theta*T/(c_k*q0)`，令 `v_k=e_k*U_k,F=v_i+v_j,d=v_i-v_j`；反解状态 `x=Y(tau,d)`，`f(tau,d)=F(tau,Y)`、`J=Y_d>0`。原 HJB 给出

- `Y_tau=D*Y_dd/J²-f_d/(2*J)`；
- `f_tau=[D*f_dd+(f_d²-1)/4]/J²`；
- 产出增益 `H_tau=[D*H_dd+f_d*H_d/2]/J²+[1/2+f_d*(Phi(Y/sqrt(Q))-1/2)]/J`。

策略为 `(1+f_d)/(2J)` 与 `(1-f_d)/(2J)`，故需同时检查 `J>0,abs(f_d)<=1`。终端 `Y=sqrt(S_T/q0)*Phi^{-1}((d+e_j)/(e_i+e_j))`，f 为连接端点值的仿射函数。该推导提示一种无需非局部反射索引的局部系统；**该离散试验现已执行，尚不能修复剩余强例**。同一坐标内的代数收益恒等式不能替代独立原状态最佳回应检查，不能因此宣称小正精度极限稳定。

## 剩余工作与判定标准

1. **先明确剩余候选和影响范围。** 区分失败候选、成功但未通过独立核验的候选、分辨率误差过大的候选及比较区间重叠。重建覆盖范围需明确记录。
2. **优先处理能改变类别的候选。** 候选产出可在同风险切片下复用于不同成本点；同一类别内部未确定的最优值，不应自动阻止类别间已有严格比较，但对手类别的潜在竞争候选必须保留。
3. **弱反馈核验同时看三个层次。** 策略近似均衡、原模型对应的收益/产出评价、空间与时间收敛。不能只选择其中最容易通过的一项。
4. **零反馈需单独记录。** 原模型的正精度定义域、直接设为零的退化方程和正精度趋零的极限不等同；零精度直接求解失败不能证明小正精度设计不竞争。
5. **再做类别比较。** 只有把候选覆盖、误差和未成功候选的影响纳入后，才更新可靠类别和边界范围。当前没有新增可可靠确定的分区点。
