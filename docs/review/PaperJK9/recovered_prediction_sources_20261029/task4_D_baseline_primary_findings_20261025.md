## 描述性概率校准

零计数实际频率减预测概率，对73竞赛等权：A约−.00726，B约+.08299，D约+.06528。D在这项汇总上低估了零提交概率。随机化PIT采用五个固定种子，每模型同小时/参赛者共享U；十等分频率偏离均匀分布的描述性L1距离范围，A约.031–.042，B约.115–.128，D约.099–.113。这里只是所选十等分校准描述，不作小时独立KS检验，也不把PIT指标当作机制检验。

边际CDF/PMF使用合格训练后验链；联合稀有概率另经同目标重要性积分核验，两个数值来源均明确保留。总体校准认证还需日期切分复核和相应精度检查。
