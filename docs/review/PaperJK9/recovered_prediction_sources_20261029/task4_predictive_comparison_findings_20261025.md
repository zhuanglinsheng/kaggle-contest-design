# Task 4：两种切分的完整预测比较

四个模型在主小时切分和完整源日期切分下均覆盖全部73个竞赛；所有参数、预测积分和配对小时/计数检查通过。完整结果未删除困难案例。D是论文经验实现的一阶均衡核；C放松期限与差距系数、保留相同过滤递推形式；A为常数Poisson基准，B增加期限形状。

## 完整样本结果

分数为每小时双方联合计数的对数预测概率，先在竞赛内平均，再对73竞赛等权；越大越好，单位nats/双方小时。

一阶均衡核相对自由核的平均增益在两种切分均为正，区间均为正；相对常数基准的平均差及区间均为负。因此证据支持限制相对C的预测价值，同时也显示D没有超越最简单的A。主切分D在37/73竞赛中优于C、25/73优于A，不能把等权平均差解释为所有案例普遍改善。

D−B主切分区间跨零，日期下端极接近零，其bootstrap端点模拟MCSE约0.000150663；不能依赖早期2,000次bootstrap的偶然跨零情况作稳定判断。两种切分高度重叠，不能当作独立样本合并缩窄区间。C的自由系数也影响过滤漂移，本比较评价同一递推形式内的核限制，不单独识别战略优化或真实Nash均衡。

## 数值核验与来源

D−C的跨竞赛积分MCSE保守和在主/日期切分约0.000797314/0.000785187；D−A约0.000260059/0.000250317。它们是Monte Carlo诊断，不是严格确定误差界，竞赛bootstrap另行表示竞赛间不确定性。

日期3960采用同一生产样本上的所有小时联合积分，保留共同分母和跨小时协方差，未与旧独立尾部均值拼接。1m/2m/4m三个新预算连续通过全部小时和整例门槛；最终整例MCSE约0.000423144，最小小时分子ESS约29,291，最大小时log概率MCSE约0.00610，最大分子权重约0.000537。43项独立尾部交叉对照全部通过；1339/1343的旧分歧已用三个新独立预算和原目标核验修复，旧记录完整保留。

49个训练参考/最高训练和分子权重点与原Stan及独立Python核对，训练密度最大误差约4.09e−12；任一log概率≥−100的完整路径项最大误差约1.67e−8。6项较大的绝对对数差只涉及概率小于exp(−100)的项，逐项概率有exp(−100)上界；全路径数组及原绝对对数检查失败均保留，概率尺度的复核标准单独记录。积分门槛、训练密度门槛及有效概率的对数门槛保持不变。

## 校准与适用范围

五个固定随机化PIT种子使用跨模型同小时/参赛者的相同U，按竞赛汇总。主切分A的描述性十等分L1约0.031–0.042，D约0.099–0.113；D低估零提交概率。这是边际校准描述，不作小时独立KS检验或机制证明。边际CDF/PMF来自合格训练链，联合概率的独立积分来源另行记录。

参数权重固定为相应训练窗后验，每小时先预测，再用小时末公共值更新状态。比较条件于事后焦点对、构造的日内时间和给定构造终点，不是原始真实时钟及当时期限公告下的实时外部验证；D也不是非线性均衡重新估计。Task 4的聚焦比较已完成，论文和正式实现未修改。
