# Task 4：完整主切分的预测比较及日期复核

主切分四模型均覆盖全部73个竞赛，并通过既定参数与预测积分门槛。D为论文经验实现的一阶均衡核，C为放松期限/差距系数、保留同一过滤递推形式的活动核；A为常数Poisson基准，B增加期限形状。以下比较不使用成功子样本。

## 主切分结果

分数是每小时双方联合计数的对数预测概率，先在竞赛内平均，再对73个竞赛等权；越大越好，单位nats/双方小时。所有模型的实际评分小时和计数已逐项匹配。

D−C的积分MCSE保守和约0.000797314，D−A/D−B约0.000260059；这些是Monte Carlo诊断，不是确定误差界。D在37/73竞赛中优于C、25/73优于A，等权平均增益不等于大多数案例普遍改善。

现有结果支持：在所检验先验和训练窗下，一阶均衡核限制相对自由活动核改善平均预测；但这一模型仍低于最简单的常数强度基准。D−B主切分区间跨零。因此不能把本检查写成论文模型普遍优于非战略基准，也不能将D−C解释为战略行为或真实Nash均衡的识别证据。C的自由系数同时影响漂移递推，此比较是同一递推形式内的核限制比较，不是只改变提交强度且固定全部状态路径。

## 日期切分：D与基准已核验，D−C暂待剩余精度

完整源日期边界切分中，D及A/B均完整73例通过。D−A平均−0.056970332，500,000次竞赛bootstrap区间[−0.101208530, −0.019244378]，负差与主切分一致。

D−B平均+0.117900639，区间约[−0.000053751, +0.268140949]。下端的bootstrap模拟MCSE诊断约0.000150663，接近零，不能把早期2,000次随机结果偶然落在零上方或下方当作稳定的显著性区别。主切分也未提供区间完全为正的证据。

C日期后验已齐备，部分预测积分仍在补足；当前不解释或发布日期D−C排名。不能把两个重叠切分当作独立样本合并以缩小区间。

## 校准与解释范围

五个固定随机化PIT种子使用跨模型同小时/参赛者的相同U，按竞赛汇总。主切分A的描述性十等分L1约0.031–0.042，D约0.099–0.113；D也低估零提交概率。这些是边际校准描述，不是小时独立KS检验或机制证明。联合稀有概率来自经过原Stan/独立Python核验的同训练后验积分，边际CDF/PMF保留合格训练链，两种来源分别记录。

所有预测均以训练窗后验固定参数权重，当前小时预测完成后才用小时末公共值更新状态。比较条件于事后选定的焦点对、构造的日内时间和给定构造终点，不是原始真实时钟与当时期限公告下的实时外部验证。D是经验一阶核，不是非线性均衡重新估计。
