# Task 4：聚焦的提交预测比较方案

更新日期：2026-10-25。当前状态：两种切分四模型各73例评分及精度核验全部完成，配对比较和500,000次竞赛bootstrap已核对。最新结论见[完整比较报告](task4_predictive_comparison_findings_20261025.md)。下文保留方案和此前实施阶段的记录，不以其中早期覆盖计数代替当前验收。

## 要回答的问题

检验论文的一阶均衡提交核，相比简单活动强度及具有相同过滤结构但放松提交核限制的模型，是否提高未来提交计数预测。比较不直接证明真实参赛者遵循 Nash 均衡，也不验证全部非线性机制。

## 四个聚焦模型

| 模型 | 内容 | 作用 |
|---|---|---|
| A：常数活动率 | 每位参赛者独立常数 Poisson 率；Gamma(.5,.5天) 先验 | 最简单且允许训练零事件的概率基准 |
| B：期限活动率 | A 加共同剩余期限幂函数，指数 beta~N(0,1)；仍无战略机制 | 检验可预测的期限形状能解释多少 |
| C：自由活动核＋同一过滤器 | 保留论文的观测模型、左端递推、活动测量比例和初始约定；自由估计核的期限及差距系数 | 分离特定均衡提交限制相对过滤框架的增量 |
| D：论文模型 | 当前一阶均衡提交核及统一先验 | 待检验的受限模型 |

C 可具体定义为 `m_k=theta/(c_k*sqrt(2*pi*Qref))*(Q_t/Qref)^(-a)*exp(-b*ytilde_t²/(2*Q_t))`，`Qref=S0+sigma²*T`，`a~N(.5,.5²),log(b)~N(0,.5²)`。D 固定 a=.5,b=1，精确退回原核；C 的 c 参数只作为匹配先验的活动尺度，不作努力成本的结构解释。C 通过 m_i-m_j 更新过滤漂移，但不要求该活动规则满足博弈最优性。C/D 的其他先验、r 测量、时间索引和观测窗口一致。该嵌套模型现已独立实现、编译，并在六个训练数据上通过完整密度/梯度校验；实际预测增量比较仍未完成。

B 使用已知完整期限的剩余比例 `(T-t)/T`，以区间左端 t 定义活动率。先固定一个时间系数，避免通过试多个模型挑选有利结果。A/B 的率先验以天为单位；训练暴露时间不含被排除的最初 23 小时。

## 信息来源核查结果与保留范围

哈希一致和训练路径为完整路径的前缀，不等于证明预处理未使用未来信息。已进一步从 ZIP 中的 Teams/Submissions 回放当前预处理：扫描 16,139,367 行源提交，所选竞赛保留 1,452,317 个有公私得分的提交，73/73 冻结输入的提交时刻、初始化、公私路径均完全一致。当前源代码按提交日期、ID 和固定种子分配日内时刻，不能恢复真实日内时刻。

- 73/73 初始联合公共输入的两个源提交均早于预测截止。4104 的零训练计数参赛者 j，其初始分数来自构造窗口第 13.275 小时的提交，在计数起点第 23 小时之前、初始化区间内；其后首个计数提交约在第 431.226 小时，晚于训练截止 407。不能将“零训练计数”解释为初值来自预测期，也不能将“计数窗口前”误写为“整个构造数据窗口前”。
- 上游 UTC+8 完整日期边界切分对 73 个竞赛均有效；A/B 已实际评分。该切分有 19,705 个预测小时，原小时切分为 18,936。C/D 尚需按该训练窗口另行拟合，不能复用原小时切分的较长训练后验。

## 首要指标与数值检查

- 首要指标是每个竞赛的平均“双方每小时联合提交计数”对数预测分数，再对 73 个竞赛等权比较。联合分数对共享参数先积分双方 Poisson 概率的乘积，不能误写成分别积分后相加的两个边际分数。
- 计数得分包含阶乘项；原估计连续事件时间目标中的数据常数不能直接当作规范化计数预测分数。
- C/D 对训练后验抽样积分，以 logsumexp 计算概率；后验抽样数加倍检查数值差，微小模型差若未超过积分误差则报告不确定。
- 参数训练后固定，逐时仅更新状态，所有模型采用同一冻结训练规则。将其称为利用实时公共信息的概率预测规则，不与用全部预测期读数平滑后的条件密度混用。
- 报告成对分数差及竞赛层 bootstrap 区间；参与者边际分数、零事件概率校准、逐小时随机化 PIT 为次要诊断。小时不能当作独立竞赛扩张显著性。
- 不把根据预测期实际公共路径累加的逐时预测，称作训练截止时对整个预测期的无条件总量区间覆盖；如要检验后者，需要另模拟未来公共信号与状态。

## 接续实施

信息来源与 A/B 的可复核概率预测已完成。当前分别拟合 C/D 的 73 个 early 后验，并对接受子集计算概率评分；还需 C/D 完整日期切分的稳健性核验。采样采用仓库最终中位数协议的四链混合门槛，保留均值 MCSE，并单独核验预测积分精度。所有新模型为审查用独立快照，不改论文或现有生产实现；新估计和报告分别记录来源、训练窗口和范围。
