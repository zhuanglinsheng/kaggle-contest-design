## 计算流程

1. **恢复缺失原后验**：`rebuild_posterior.py`保留此前6场已接受链，按冻结原Stan模型、原输入、原统一先验恢复其余67场。不是非线性重估。使用原最终中位数协议：4链、无发散/树深饱和、BFMI>=.3、rank Rhat<=1.01、bulk/tail ESS>=400；未通过则按冻结日程加长抽样。源模型、输入、原始链哈希逐例保存。
2. **原模型搜索**：`design_batch.py`等后验可用即开始。期限原网格(.1,.25,.5,.75,1,1.25,1.5,2)；保留原反馈、完全披露及共同绝对精度网格。直接搜索奖金并局部加密可行交叉，不使用一阶奖金反解，不假定产出全局单调。失败候选保留为未知。原设计作为恒可行兜底。
3. **原模型质量校核**：为降低耗时，采用粗/细网格多层Monte Carlo。两层都是原非线性模型，不是首阶努力近似。条件于原已接受经验后验，独立均匀有放回抽样：每链1点用于筛选、32点估计粗层质量差、另4点估计细减粗校正。后两组独立；均值估计为E[C]+E[F-C]，对细层经验后验均值无偏。配对原设计/候选共用同一联合参数点；MCSE来自两独立组的分层方差，使用Welch-Satterthwaite t临界值。细层空间/时间差三倍及边界预算另外扣除；不是严格连续误差界。原始MCMC误差与此条件积分误差分开理解。
4. **全披露比较**：对每个delta另搜原非线性模型的全披露基准；最后一列仍只取正奖金、非全披露所选设计。不能以保持原反馈的成本冒充全披露基准。

## 数值实现及修复

编译HJB最初的物理均匀网格在高精度下需要分辨很窄的终端Gaussian，严重拖慢搜索。新`pipeline/theory/nonlinear_similarity_kernel.cpp`使用严格坐标变换：z=y/sqrt(h_T+tau)，s=log(1+tau/h_T)。梯度方程仍为原耦合非线性HJB；产出方程同步变换、保留原Riccati路径，初始反馈层用几何时间点分辨。没有截断候选精度或改模型。粗层极强激励时采用更稳的一阶**空间**通量，这是数值离散，不是leading-order策略；多层细校正仍针对原模型。

六代表点进行了四层收敛，见similarity_validation.json（初版）；随后发现目标时间网格的近零舍入导致小精度分支虚假-6报错，已修复并重算独立检查。当前similarity_independent_checks.json显示2551原/半/双精度与独立价值HJB差约.00063--.00072（该空间网格仍需细化）；精度1e6与解析全披露极限差约.00021。它们是方法检查，不是正式表的质量证书。

原价值HJB的粗层有时失败而细层成功。现通过独立相似坐标两层求解复核：有有效价值HJB结果时要求其与相似坐标差落在加密诊断内，并将差计入半径；纯资源不足允许原模型相似坐标替代。若两层均出现非单调值梯度，仍保留未知，不用任意“修复”值填满。恢复结果缓存于fine_recovery，重复候选不会重复求同一基准。
