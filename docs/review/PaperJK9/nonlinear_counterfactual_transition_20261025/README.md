# 计算原则更正：估计使用一阶策略，估计后的设计分析使用原模型

用户最新明确的原则优先于此前“检验一阶反事实方向”的工作口径。一阶近似仅用于构造贝叶斯参数后验；原后验及其先验保持不变。之后的质量基准、候选评价及反事实设计选择直接使用原非线性游戏。方向一致性检查保留为近似诊断，不再作为反事实计算的前提。

## 实现

- 新入口：`pipeline/empirical/nonlinear_design.py`。
- 有限正精度：原价值HJB的自适应时间求解器及原产出漂移恒等式的线性PDE，双方成本分别保留。
- 完全披露：`pipeline/theory/asymmetric_full_output.py`，将已独立核验的非对称解析策略与价值坐标产出方程转为正式模块；平均原初始先验，不丢掉初始不确定性。
- 零奖金：原模型的无努力解析产出，不调用一阶努力公式。
- 每个后验点固定原mu和S0=sigma/sqrt(lambda_obs)，精度干预只改变后续学习路径。
- 原设计基准和候选质量都用非线性模型，不能继续沿用一阶目标。
- 直接搜索奖金、期限及共同反馈规则，不再通过(target-B0)/A反解奖金，不预设奖金—质量单调。
- 每个候选完整保留选定的后验抽样；任何抽样数值失败则该候选未知，不计算成功子集均值。不将失败解释为低质量。
- 保留原设计作为可行选项，逐延迟成本情景比较；任何更便宜但未知的候选都在结果中列出。

当前是明确候选网格上的搜索实现，尚不是连续域全局优化证明；默认每链8个分层抽样只作筛选，可用参数0使用全部原保留抽样。平均质量约束另报配对MCSE和网格诊断半径；后者不是严格连续误差界。候选筛选与验证若使用同一抽样，不能据此声称独立验证；正式替表还需扩大原后验抽样范围及候选搜索/独立数值核验。

## 停用旧流程作为当前反事实入口

`fixed_initial_design`保留原数学函数及历史结果，但命令行必须显式给出`--legacy-first-order`才运行。这样不会误将旧一阶表重新生成后当作非线性结果。没有把旧表改名，也没有把仍基于一阶质量的论文表改写成已完成的非线性分析。

原48项先验/边界检查中的参数后验仍可复用，但其中通过一阶质量反解奖金的政策结果只是历史诊断；若用于新版反事实稳健性，需要用本流程重算。Task4已有比较是“一阶均衡核”的预测结果；若将其作为原非线性模型的预测证据，也需在保持相应训练后验的基础上另做非线性预测，不能直接改标签。
