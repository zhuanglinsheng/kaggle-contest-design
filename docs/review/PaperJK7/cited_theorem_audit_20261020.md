## Nishida 积分方程版本

[原始讲义](https://bibliotheque.imo.universite-paris-saclay.fr/media/filer_public/bb/b2/bbb2303a-1e17-4807-a319-290a5b030b2f/n_nishida-102.pdf) 的 Remark 2.3 确实处理前向积分方程，而非仅给出抽象微分方程的版本。

逐项对应：

| 所需输入 | 本文对应 |
| --- | --- |
| 嵌套 Banach 空间与单调范数 | 指数 Fourier 范数；较大解析半径的空间嵌入较小半径空间 |
| 初始函数路径连续且范数一致有界 | u0(t) 为 Gaussian 传播后的终端密度；由传播收缩控制 |
| 半径 R 严格大于初始界 | 稿件选 R>2‖h(0)‖ |
| 非线性在相邻尺度之间连续 | 乘法与一阶空间微分的标准 Fourier 估计 |
| Lipschitz 常数只损失一个解析半径 | C alpha_* R/(rho−rho')，经 upsilon=alpha_* tau 重标度消去 alpha_* |
| 零输入处的增长条件 | 非线性为二次通量的导数，N(0)=0 |
| 正时间存在区间 | Remark 2.3 的时间从 0 向前；不需要为负传播时间求解逆热方程 |

时间重标度可能使传播子的时间变化很快，但这里使用收缩性和连续性，不要求对该变化速率给出统一导数界。为给积分核定义完整的正时间矩形，可把确定性扩散路径在物理区间外连续延拓；这不会改变所需区间内的解和范数常数。引用本身没有发现条件缺失。

## Ryvkin 完全披露解

使用本地原文 `docs/references/Ryvkin - 2022 - To Fight or to Give Up Dynamic Contests with a Deadline.pdf`，核对 Proposition 1、对称特例 (18) 和 Proposition 3 的价值公式 (23)。

令原文奖金 V=theta、两人成本均为 c、w=theta/(c sigma²)，并取原文 rho=tanh(wd/2)。原文的 gamma 函数满足

    gamma(tanh(wd/2))=(sinh(wd)+wd)/2=w K(d)。

所以原文 (18) 的隐式关系恰变成本文

    K(d)=K(1)(2Φ(z)−1)。

价值公式换元给出 Ui+Uj=f(d)、Ui−Uj=d；交叉核对端点为 0、1、两者总奖金为 1。能量恒等式则由原文价值的“奖金收入减努力成本”定义得出，不是直接把它误标成 (23) 原文中的另一个公式。

## Jackson 经典解结果

[已核对的预印本原文](https://arxiv.org/html/2206.08334) 为 v2。其 Theorem 2.7 是对已存在经典解的梯度估计；存在唯一性的结果是 Theorem 2.8，条件为 H_AB、H_Reg 及足够光滑的终端值。正式发表版本未成功取得，暂不修改论文中的 2.7。

本文映射及条件检查如下：

| 条件 | 验证 |
| --- | --- |
| 空间维度和解维度 | 一维状态、二维价值；定理允许该系统 |
| 对称且一致非退化的扩散矩阵 | 取原文扩散系数 sqrt(a_t)；固定 0<lambda<∞ 时 a_t=lambda S_t² 在有限区间内有正上下界 |
| 关于状态、价值的系数条件 | 扩散仅依赖时间，driver 不依赖状态和价值 |
| BF 二次结构 | ‖F_k(z)‖≤C‖z_k‖‖z‖，符合所需的逐分量结构 |
| Q 局部 Lipschitz | F 是二次多项式；梯度差受 C(1+‖z‖+‖z'‖)‖z−z'‖ 控制 |
| AB1 分解 | 共同漂移为 alpha_i z_i+alpha_j z_j，剩余分量为 −alpha_k z_k²/2 |
| 正生成向量 | 取 ±L e_k、L≥max(alpha_i,alpha_j)>0；两种符号的 AB 上界分别成立 |
| Reg 时间正则性 | 扩散路径光滑，driver 不依赖时间 |
| 终端值 | S_T>0，Gaussian CDF 及其补函数属于所需的有界光滑类 |
| 解的有界性及有界梯度 | 可读原文的经典解定义及其存在定理涵盖该范围 |

因此现阶段的问题是版本定位，不是已确认的定理不适用。尤其不能说“预印本 2.7 本身已经证明存在性”；正确的数学支撑应是经典解存在唯一性结果。

## Kato 与 Lorenzi

[Kato 原文](https://webhomes.maths.ed.ac.uk/~v1ranick/papers/kato1.pdf) 的版本页明确标示 1980 版重印。第 VII 章第 1–2 节讨论解析算子族、共同定义域及分离谱投影。这里 A_w 的相对一阶扰动、解析系数及孤立简单领先特征值已在逐行复核记录中具体建立，故使用方向正确。该引用没有被用来替代全时非线性稳定性的证明。

[Lorenzi 等原文](https://people.dmi.unipr.it/alessandra.lunardi/LectureNotes/I-Sem2005.pdf) 的 Proposition 3.2.2(ii) 给出中间空间平滑，(iii) 处理从中间空间到基础空间的扰动；第 5 章处理线性长期行为。Theorem 7.1.3 需要负谱界、适合的中间空间，以及在零点附近 Lipschitz 常数趋零的非线性。本文取 alpha=7/8，空间和二次余项满足这些条件。

还核查了两点容易被忽略的限制：

- 引用不能直接保证不同算子的分数幂定义域相等。本文可在固定 A0 的插值空间中证明所需估计，无须加上这一结论。
- 单独引用 Theorem 7.1.3 不会自动给出复参数统一性。本文先建立共同参数邻域中的算子与初值界，再作统一 Duhamel 收缩，故复参数分析有另行依据。

## Bensoussan 与两篇滤波补充引用

[出版社原书目录](https://assets.cambridge.org/97805216/11978/frontmatter/9780521611978_frontmatter.pdf) 可确认：正式书名为 *Stochastic Control of Partially Observable Systems*；第 1 章为 Linear filtering theory，第 1.2 节为 Filtering theory in continuous time，起于印刷页 11。

已确认的两处小问题是：

1. `_Literatures.bib` 中书名的 `Observed` 应为 `Observable`。
2. 正文 `Chapter 1.2` 应称 `Section 1.2`。

这两项由出版社原书信息支持，不是根据题目猜测正文内容。相关完整章节未取得，所以不宣称已核实其具体定理编号和全部假设。

就本文模型本身，初始高斯、独立创新与测量噪声、已知参数及公开可预测努力输入，给出标量滤波形式

    d(mean)=(q_i−q_j)dt+lambda S(dZ−mean dt)，
    S'=sigma²−lambda S²。

将创新定义成 sqrt(lambda)(dZ−mean dt)，即得到稿件的 sqrt(lambda)S dBhat。这里的公开控制输入与私有状态信息必须按论文假设区分；不能把连续滤波结果无条件当成异步读数行为递推的精确结论。稿件已明确区分。

[Barrau–Bonnabel 原文预印本](https://arxiv.org/html/1410.1465) 主要是 Lie 群上的 invariant EKF 及其局部稳定性，不是本文线性高斯条件分布的直接定理来源。现稿只将它列为 see also，不构成本文某项证明的定理调用；因此不将其计作数学误用，但它不是主要证明依据。

Frogerais 等讨论 continuous-discrete EKF 的数值实现，本轮仅取得检索信息，未成功取得全文，不据此提出实质性替换或改动。

## Berge 与最优值取得

Berge 原书相关正文未取得，故不能将 Chapter 6 的具体定理表述标为原文复核完成。

不过本文实际需要的结论可直接核实：只对全披露问题固定参数后，在奖金与期限的有限闭矩形中优化；已有候选的收益至少为 V0，预算上界排除矩形外的竞争设计，边界连续性单独由能量控制建立。因此连续目标在非空紧集上取得最大值。之后再用独立引理排除有限精度设计。

这一步没有要求在原始非紧设计集上直接套用 Berge，也不需要尚未证明的参数化可行集连续性。数学用途未发现问题，原书引用定位仍按证据范围保留。

## 未单列文献的标准工具

还检查了证明中使用 Itô、Feynman–Kac 和 Girsanov 的条件。固定正有限精度下扩散有正下界，经典解的相应导数与反馈漂移有界；Girsanov 所需的漂移除以扩散系数在有限区间有界，满足 Novikov 条件。均衡验证中的偏离仍以适应、非负且平方可积的通常 admissibility 为前提。这些不是本轮发现的新错误。
