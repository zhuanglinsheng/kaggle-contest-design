# Current results

This directory contains outputs from the current PaperJK7 pipeline:

- `estimation/main/`: baseline full-path and early-path posterior fits;
- `estimation/robustness/`: alternative focal-pair fits;
- `counterfactual/main/`: Chapter 5 posterior counterfactuals;
- `validation/main/`: Chapter 5 diagnostics and regressions;
- `validation/robustness/`: Chapter 6 robustness diagnostics;
- `synthetic/`: regenerated synthetic recovery experiments.

Large raw chain files are reproducible intermediate artifacts. Compact final
summaries and accepted-chain manifests provide the provenance used by later
stages.
